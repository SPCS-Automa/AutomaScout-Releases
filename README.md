# AutomaScout — Releases

Este repositório contém apenas os binários portáteis do AutomaScout
(simulador de subestação IEC 61850 / DNP3 / Modbus da Automa) e as notas
de cada versão. **Não há código-fonte aqui.**

## Downloads

Veja a aba [Releases](../../releases) para baixar a versão mais recente.

- **Windows**: `AutomaScout-Windows.exe` — execute diretamente, sem instalação.
- **Linux**: `AutomaScout-x86_64.AppImage` — dê permissão de execução
  (`chmod +x`) e rode.
- **AutomaScout-Licenca** (`.exe` / `.AppImage`): mostra o código de
  instalação da sua máquina e instala uma licença recebida da Automa.

## Licenciamento

O simulador requer uma licença válida (ou uma conta do domínio Windows da
Automa/DNV) para abrir. Para solicitar uma licença, abra o
`AutomaScout-Licenca`, copie o código de instalação exibido e envie para
o seu contato na Automa.

## Suporte

Em caso de dúvidas ou problemas, entre em contato com o suporte da Automa.
